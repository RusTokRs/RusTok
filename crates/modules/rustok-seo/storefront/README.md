# rustok-seo-storefront

Storefront and client UI support crate for `rustok-seo`.
Provides framework-agnostic SEO data structures, dual-path transport adapters, and SSR head rendering helpers for Rust storefront hosts (`apps/storefront`, Dioxus storefront).

For detailed public surface, architectural invariants, and capabilities, see [CRATE_API.md](CRATE_API.md).
