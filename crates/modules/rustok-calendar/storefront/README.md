# rustok-calendar-storefront

For full public interface and operational contract definitions, see [CRATE_API.md](CRATE_API.md).

Storefront UI package for `calendar`, following Fluid Frontend Architecture (FFA).

## Responsibilities
- Pure Rust view-models in `core`
- Decoupled backend communication via `transport`
- Leptos UI components and templates in `ui`
- Localization catalog in `locales/`
